# Marine Invoice

Offline invoicing for marine fiberglass repair with a built-in parts and materials catalog.

Made with [CodeAgent Remix](https://www.codeagent-mobile.com/remix). Live app: https://marine-invoice-qfy6uu2c.remixapps.app/

## Run it on a desktop computer

This app can run in a desktop browser as well as on iOS and Android. You need Node.js 20 or newer.

```bash
npm install
npm run web
```

Expo starts the app and opens it in your browser. The app includes sample invoices to explore and edit.
Your invoices, catalog, and settings are saved in that browser on this computer; they are not synced
with the mobile app or other browsers. Clearing the browser's site data will remove them.

## Run on a phone

```bash
npx expo start   # scan the QR code with Expo Go
```
