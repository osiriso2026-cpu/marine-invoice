# Marine Invoice

Offline invoicing for marine fiberglass repair with a built-in parts and materials catalog.

Made with [CodeAgent Remix](https://www.codeagent-mobile.com/remix). Live app: https://marine-invoice-qfy6uu2c.remixapps.app/

## Run it locally

A React Native app for [Expo](https://expo.dev) (SDK 54), in TypeScript. You need Node.js 20 or newer.

```bash
npm install
npx expo start   # scan the QR code with Expo Go
```
